# hamburger-animation

A CSS hamburger menu animation (`index.html`, `style.css`, `main.js`) plus a
video and motion graphics studio in `studio/`.

- Keyword guide for video work: `studio/README.md`
- Put source footage in `studio/media/`; write renders to `studio/out/`.
- Use `studio/.venv/bin/python` and `studio/.venv/bin/manim`, not the system Python.
- Run Node video tools (`remotion`, `hyperframes`) from inside `studio/`.
